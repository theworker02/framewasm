# framewasm

Frame validation gates for wasm inputs before they hit prod.

**Site:** https://theworker02.github.io/framewasm/

## Install / run

```bash
git clone https://github.com/theworker02/framewasm.git
cd framewasm
node src/cli.js
node --test
```
